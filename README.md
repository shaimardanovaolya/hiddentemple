# Сканер дрона

Дважды щёлкните по **Play.cmd**. Если игра уже открыта, обновите страницу. Оставьте окно сервера открытым до конца игры. Для запуска нужен установленный Python 3.

На поле 4×4 четыре предмета. Свиток занимает три клетки в ряд, печать — квадрат из четырёх клеток, чип — две соседние клетки, батарейка — уголок из трёх клеток. Одно сканирование тратит одну попытку и 3 заряда. Чтобы собрать предмет, откройте все его фрагменты. После двух пустых плиток можно бесплатно подсветить одну нужную клетку. Сканирование подсвеченной клетки тоже расходует попытку.

Миниатюры в витрине показывают форму и ориентацию предметов на текущем поле. По умолчанию даётся 14 попыток. Победа засчитывается сразу после сборки четвёртого предмета, в том числе на последней попытке. Если попытки закончились, а витрина ещё неполная, нажмите «Начать заново».

Поле и оставшиеся попытки сохраняются после обновления страницы. Кнопка ↻ создаёт новое поле. В настройках ⚙ можно выбрать от 12 до 16 попыток для следующего раунда и изменить длительность вспышки.

Кнопка «Проверить винрейт» в настройках перебирает все возможные раскладки и показывает результаты для лимитов от 1 до 16 попыток. Модель учитывает миниатюры предметов, открытые плитки и бесплатную подсказку. Текущий раунд и настройки при проверке не меняются.
